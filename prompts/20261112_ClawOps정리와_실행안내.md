> 안내 최신버전에 맞게 갱신해주고 팀원이 클로옵스를 사용하기로 최종결정했기때문에 일전에올린 vapi 관련된 불필요코드를 정리해달라는 요청도있었어

사용자 후속 요청:

> 안내갱신및 vapi코드 정리 라는 이름으로 깃에 업로드 후 pr까지 진행하자

후속 범위는 같은 제목의 커밋·작업 브랜치 업로드·PR 생성과 자동 검사 확인이다. main 병합·운영 배포는 포함하지 않는다.

## 기준과 변경

- 기준 main: PR51 `dce78f0203a5b9b42c2273f994f3828ac5a78c41`. 작업 브랜치: `chore/clawops-only-guide`.
- 공동·프론트 안내를 Node 24·Vite 5173/4173과 현재 가입·학원 API에 맞춤. 새 프론트·음성 설정 예제, 공동 연결/전체 개인 환경/목업·실통화 시험 구분 추가. Compose CORS 주소도 5173으로 맞춤.
- 사용하지 않는 `backend/provider6.py`, `voice/engines/register_vapi_trunk.py`, `voice/engines/setup_test_agents.py` 제거. 백엔드의 해당 변환 예제 전용 시험 8개 제거.
- 서비스 에이전트가 이전 비교 도구에서 가져오던 ClawOps 공통 기능을 `clawops_agents.py`로 분리. 기존 요청 본문·모델·음성·프롬프트 동일성 확인, ClawOps 설정만으로 생성 요청을 만드는 회귀 시험 2개 추가 및 CI 연결.
- 기존 DB 이력 테이블·스키마, 실통화 허용 정책·1회 제한, 개인 설정은 보존. 과거 측정 데이터·분석 코드·회의록·논문·기존 AI 사용 기록 보존. 과거 도구 링크는 정리 전 고정 커밋으로 연결.
- 이전 검토 R01 자동 조회 잔존과 R02 실제 학원 목업 표기는 이번 변경 대상과 구분.

## 검증과 반영 범위

- 별도 MySQL·Redis의 백엔드 189개, 목업 30개, 실통화 워커의 가짜 제공업체 시험 54개, 배포 도구 14개, 에이전트 도구 2개 통과. SQLite에서 의도적으로 제외하는 MySQL 행 잠금 매개변수 1개 건너뜀, MySQL 매개변수 통과.
- 기존 ClawOps 서비스 에이전트 본문과 정리 후 본문을 동일 프롬프트로 대조해 완전 일치. 설정 파일 해시 보존 확인.
- OpenAPI·워커 명세·결과 스키마·SQL·데이터 사전·ERD를 현재 소스에서 별도 재생성하여 6개 파일 내용 동일 확인. DB 접속·DDL 적용 없음.
- 기존 개인 설정·node_modules가 없는 새 프론트 폴더에서 설정 예제 복사·npm ci·타입·37개 화면 회귀·빌드 성공. 개발 화면/옵션/학원 목록과 빌드 미리보기 HTTP 200. 전체 합계 326개 통과·실패 0개·의도적 제외 1개. 이전 332개에서 Vapi 전용 8개를 제거하고 ClawOps 회귀 2개를 추가한 결과다.
- 작업 브랜치 업로드·PR 생성은 사용자 후속 요청 범위다. 원격 main 반영과 공동 서버 배포는 별도다.
