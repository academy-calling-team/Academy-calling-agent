## 결과를 어떻게 썼는지

- Claude가 `experiments/latency/data/human_result/human_1013.csv`로 직접 측정 통계를 다시 계산해 README 값과 맞는지 확인했다(ClawOps 49개 중앙값 1.57초, Vapi 48개 중앙값 1.40초, p95는 nearest-rank로 1.98초와 1.78초).
- `docs/음성_엔진_비교_측정.md`: 자동 분석 값(−50dBFS 기준)은 그대로 두고 직접 측정 값을 나란히 적었다. 직접 값이 평균 0.04초 짧은 것은 김규림 README의 재계산대로 소리 크기 기준 차이로 설명했다. 자동 분석이 잘못 잡은 것으로 보이는 두 곳(Vapi A2 첫 응답, ClawOps D 한 조각)은 다시 들어 확정할 항목으로 남겼다. '0.6~1.0초 응답'은 직접 측정에 맞춰 0.8~1.0초로 고쳤다.
- 노션의 7주차 회의 사전 공유, 통화 실험 기록 등 같은 숫자를 쓰는 곳에도 직접 측정 값을 같이 적었다.
- 회의 진행용 자료는 노션 '7주차 회의 사전 공유' 아래 하위 페이지로 만들었다. 팀원 디스코드 공지의 순서를 따르고, 항목마다 배경과 기술 설명을 덧붙였다.
- 브랜치로 올려 PR에서 팀원 검토를 받는다.
- 강유준의 판단에 따라 Vapi A2 첫 응답과 D2 첫 세 응답(0.8~1.0초)은 AI가 되짚는 질문 뒤 답을 기다리지 않고 말을 이어 간 자리에 사람이 대답한 것으로 보고 응답 지연 통계에서 뺐다. `human_1013.csv`에서 이 4행의 latency를 0으로 바꾸고 이유를 note에 적었다.
- 비교 문서의 지연 수치를 모두 사람이 뷰어로 잰 값으로 바꿨다(ClawOps 49개, Vapi 44개). Claude가 같은 CSV로 평균, 중앙값, p90, p95(nearest-rank), 통화별 중앙값, 부트스트랩 구간, Mann-Whitney 검정, 대본 A~E 분위수 차이를 다시 계산했다. 자동 분석 수치는 `experiments/latency/README.md`에 그대로 남아 있다.
