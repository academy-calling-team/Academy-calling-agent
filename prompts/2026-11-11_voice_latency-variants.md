## 결과를 어떻게 썼는지

- Claude가 시험을 설계하고 도구를 만들었다.
  - 짧은 프롬프트(`voice/prompts/agent_prompt_v3_short.txt`)를 썼고, 김규림이 초안을 승인했다.
  - ClawOps 시험 에이전트 S·M을 만들었다(김규림 확인 후).
  - 발신 도구(`experiments/latency/scripts/variants_1111.py`)를 만들었다.
- gpt-realtime-2.1-mini를 쓸 수 있는지와 realtime 설정 형식은 ClawOps 공개 API 명세(openapi.json 1.3.2)에서 확인했다.
- 묶음을 가리고 재기 위해 Claude가 다음을 넣었다.
  - 측정 번호, 무작위 순서(균형 유지)
  - 통화 중 즉시 메모
  - 측정용 사본
- 김규림이 18통을 걸고, 휴대폰 녹음을 뷰어로 직접 쟀다.
  - Claude는 스크린샷 값을 CSV로 옮기고, 통화마다 화면의 응답 수·평균·중앙값과 대조했다(18통 모두 일치).
  - 09·10번의 빠진 첫 간격은 Claude가 −60dB로 계산해 원인을 찾았다. 김규림이 직접 다시 잰 값이 계산값과 같았다.
- 녹음 폴더를 날짜별로 정리하면서 분석 스크립트가 날짜 폴더에서 녹음을 찾도록 고쳤다(`scripts/paths.py`의 `rec_file`).
- Claude가 행동 표를 처음 정리할 때 '인사 없이 끊음'을 M 5통으로 잘못 셌다. README에는 메모 원문과 다시 대조한 4통으로 적었다.
- 결과와 한계는 `experiments/latency/README.md`의 '프롬프트 길이·말하는 모델 시험 (11/11)'에 있다.
