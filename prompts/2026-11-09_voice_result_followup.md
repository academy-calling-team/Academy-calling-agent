# 음성 결과 계약과 화면 연동 후속

- 날짜 · 2026-11-09
- 작성자 · 박찬원
- 도구 · Codex
- 기준 · PR #44 답변 계약, PR #45 워커 검토

## 요청

> 작업해야하는거있으면 진행해봐 요구사항 내용 반영해서 작업했다는것과 설명도 해주고 작업완료후에 나한테

## 반영

- 결과 전송 전 워커 접수 DB에 본문 저장, 재시작 후 같은 본문 재전송, 전송 종료 시 보관본 정리
- 학원의 추측·답변 보류와 질문별 근거 발화를 기존 답변 계약으로 변환
- 상담 가능 시간에 해당 학원 발화의 시간 표현 적용
- 상세 화면에 미확인 사유와 선택적 발화 원문 표시
- 판정 모델·프롬프트 버전·시도 횟수의 워커 로그 이동, 판정 실패 시 학부모 안내

## 검증

- 전송 응답 유실과 재시작, 학원 답변 보류, 근거 없는 상담 시간, 이전 답변 형식의 화면 표시 자동 테스트
- 모의 판정과 격리 환경 기준, 실발신 및 실제 모델 호출 별도
