## 결과를 어떻게 썼는지

- `voice/call_worker/`를 새로 만들었다. 목업 워커(`voice/mock_worker/`)는 고치지 않고 접수 저장, 가짜 결과, 전송 모듈을 가져다 쓴다. `is_mock=false` 요청만 ClawOps로 실제 발신한다.
- 실제 발신은 `REAL_CALLS_ENABLED=1`, ClawOps 값 4개, 받는 번호 허용 목록이 모두 있을 때만 한다. 설정이 없으면 지금 목업 워커와 똑같이 동작하므로 main에 합쳐져도 공동 서버 동작이 바뀌지 않는다.
- ClawOps API 명세(api.claw-ops.com/openapi.json)를 보고 발신(`POST /calls`의 `CallContext`), 상태 조회, 전사, 요약 호출을 정했다. 웹훅 대신 상태 조회를 써서 공동 서버에 외부 공개 경로를 열지 않는다.
- 같은 `call_id`로 다시 걸지 않도록 ClawOps 통화 ID를 저장하고, 발신 여부가 불확실한 건(응답 유실, 통화 ID 없이 재시작)은 다시 걸지 않고 거절로 기록하게 했다.
- 시험 11개(`test_worker.py`)는 ClawOps와 백엔드를 가짜로 바꿔 전화 없이 돌린다. 기존 목업 시험 30개도 그대로 통과한다. 실제 통화 시험은 팀원 휴대폰으로 사람이 직접 한다.
- 질문별 예·아니오·미확인 판정 규칙(`extract.judge`)은 Claude가 갈림길이 되는 경우 8가지를 물었고, 김규림이 답한 기준을 Claude가 코드와 시험 사례로 옮겼다. 부정어 우선, '네' 단독은 예, 추측은 미확인, 모름/거절 구분, 대기만 되면 아니오, 수업 시간은 요일·시각 필요, 상담은 시간을 말하면 가능, '어려워요'는 아니오.
- 10/13 실제 통화 16개의 로컬 전사로 확인했다. 자리·수업 시간은 16개 모두 정답지와 맞았다. 받아쓰기에서 "요일"이 "유일"로 적힌 경우가 있어 질문 키워드에 넣었다. 상담은 2개에서 AI의 상담 질문을 찾지 못해 미확인으로 남는다.
- `infra/Dockerfile.shared-worker`가 새 워커를 실행하도록 바꾸고, 배포 검사에 새 시험을 추가했다.
