# 되짚기를 숫자·시간·장소가 든 답에만 하기 (11/24)

- 날짜: 2026-11-24
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 11/18 리허설 통화(2분 19초)에서 답마다 되짚기 → "네, 맞아요" 왕복과 그때마다 약 2초의 응답 대기가 붙어 통화가 길고 끊기는 느낌이 났다. 되짚기를 꼭 필요한 답에만 하게 줄인다.

## 프롬프트

```
되짚기 줄이기 준비해줘
```

## 결과를 어떻게 썼는지

- Claude가 서비스 에이전트 프롬프트(`voice/prompts/service_agent_prompt.txt`) 4번을 고쳤다.
  - 답에 숫자·요일·날짜·시간·장소가 들어 있으면 되짚는다(숫자·요일·시간은 오전·오후까지)
  - 되는지 안 되는지만 분명한 짧은 답("네, 있어요", "그건 안 해요")은 되짚지 않고 넘어간다
  - 답이 애매하면 되짚는다. 전체 확인은 마지막 요약(6번)이 그대로 맡는다
- 리허설 대본에 대 보면 되짚기 5번이 3번(자리 수, 수업 시간, 상담 시간)으로 줄어든다. 왕복 하나가 약 8~9초라 통화가 약 15~20초(10% 남짓) 짧아질 것으로 추정한다. 실제 효과는 시험 통화로 잰다.
- 판정 쪽 영향: 학원이 되짚기에 "아니요"로 고치는 경우가 줄어 정정 감지 기회도 준다. 숫자·시간 답은 그대로 되짚으므로 받아쓰기 오류 확인은 유지된다.
- 운영 중인 서비스 에이전트는 바꾸지 않았다. PR 병합 뒤 `setup_service_agent.py update`로 반영한다(운영 변경이라 실행 전 확인).
- 워커·목업·에이전트 도구 시험 143개 통과(프롬프트 본문은 시험이 파일과 같은지만 확인).
