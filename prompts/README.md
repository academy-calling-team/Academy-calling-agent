# 생성형 AI 사용 기록

과목 요건: 생성형 AI 활용을 위한 프롬프트도 GitHub에 올려야 함.

파일 하나에 한 작업씩 `YYYY-MM-DD_파트_작업.md` 이름으로 저장.
예: `2026-10-07_voice_stt-compare.md`

## 양식

```
# 작업 이름

- 날짜:
- 작성자:
- 사용한 도구: (Claude, ChatGPT, Copilot 등)
- 목적:

## 프롬프트
(입력한 내용 그대로)

## 결과를 어떻게 썼는지
(그대로 썼는지, 고쳐서 썼는지, 버렸는지)
```

서비스 안에서 쓰는 프롬프트(통화용 대화 프롬프트, 결과 추출 프롬프트)는 여기가 아니라 `voice/prompts/`에 둠.
