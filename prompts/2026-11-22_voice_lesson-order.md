# 수업 문의 묻는 순서: 맞는 반 → 자리 → 시간 (11/22)

- 날짜: 2026-11-22
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 11/17 음성팀 제안('수업 문의 세 질문 묶기')의 음성 쪽 남은 일. 프론트는 PR #60으로 세 질문을 한 번에 고르게 됐고, 상담원이 맞는 반 → 자리 → 시간 순서로 묻고 맞는 반이 없으면 자리·시간을 건너뛰게 한다.

## 프롬프트

```
상담 프롬프트 반 자리 시간 순서 넣어줘
```

## 결과를 어떻게 썼는지

- Claude가 통화마다 넘기는 지시(`real_call.build_instruction`)에 질문 목록과 순서가 들어 있는 것을 확인했다. 서비스 에이전트 프롬프트를 바꾸면 운영 중인 에이전트를 update해야 하지만, 지시에 넣으면 워커 배포만으로 반영되므로 지시에 넣었다.
- `ask_order()`: 수업 문의 세 질문을 처음 나온 자리에 맞는 반 → 자리 → 시간 순서로 모은다. 나머지는 요청 순서 그대로.
- `lesson_skip_rule()`: 맞는 반과 뒤 질문이 같이 있으면 '맞는 반이 없다고 하면 자리와 수업 시간은 묻지 않고 넘어간다'를 넣는다. 조사(은/는, 와/과)는 받침에 맞춘다.
- 키워드 판정(`extract.positions`)이 지시 순서대로 질문을 찾으므로 판정도 같은 순서로 하고, 결과 답변은 요청 순서로 되돌린다.
- 맞는 반이 불가이고 자리·시간이 `not_asked`이면 detail에 '맞는 반이 없다고 해서 묻지 않음'을 적는다(판정 값은 그대로). 정의 확인 (2)대로 다른 답에서 미루어 no로 채우지 않는다.
- 시험 9개 추가, 워커·목업 시험 141개 통과. 실제 통화에서 상담원이 건너뛰는지는 시험 통화로 확인해야 한다.
