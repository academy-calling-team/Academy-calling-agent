# 계층 판정 규칙 수정 tiered-v2.1-spec (11/19~22)

- 날짜: 2026-11-19 ~ 2026-11-22
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 강유준의 판정 정의 확인 답(11/18)과 11/19 결정을 계층 판정(`voice/call_worker/tiered_judge.py`)에 반영하고, AI 세트 190항목 회귀로 효과와 퇴행을 확인한다.

## 프롬프트

```
이제 해야하는거
시연마무리는 했어
(당일 포함 질문에) 당일 포함, 통화 이후 시각만
(지역 확인 없는 '차량 있어요' 질문에) 미확인으로 바꿈
(remaining_days 구현 요청에) 네가 해줘
```

## 결과를 어떻게 썼는지

- Claude가 main의 계층 판정(tiered-v2-spec)으로 190항목 회귀를 3회 돌렸다(로컬, 라벨은 PR #57의 v4 초안). 퇴행 10건을 하나씩 열어 원인을 나눴다.
  - 당일 규칙 3건, 당일 규칙으로 풀릴 것 1건, 11/11 정의를 라벨이 따라가지 못한 것 5건, 판정 오류 1건(학원이 주말을 먼저 말했는데 no)
- 그 결과와 정의 답으로 규칙을 고쳤다. 규칙 문장은 판정 값 목록과 정의 답에서 가져왔고, 시험 사례 문장은 쓰지 않았다.
  - 정의 (1): 학부모가 정보를 더 알려 주면 답할 수 있다고 한 것도 redirect
  - 정의 (2): 섞인 답은 그 질문의 뜻에 직접 답한 말만 기록하고 다른 답에서 미루어 채우지 않음
  - 정의 (4): 다시 전화해 달라는 말은 unknown
  - 개정안 6번: AI가 특정 날을 물었으면 그 날이 기간
  - 11/19 김규림 결정: '이번 주 남은 날'에 통화 당일(통화 시각 이후)을 넣음. 늦은 시각 통화도 오늘을 넣고, 학원 말로 거르게 함
  - 11/19 김규림 결정: 지역(위치)에 가는지 확인하지 않고 차량이 있다고만 하면 unknown
  - 주말 규칙을 풀어 씀: 학원이 주말에 된다고 하면 평일이 안 되더라도 yes
- 코드 검사를 하나 더했다. 상담이 no인데 1차가 가능 시간을 뽑았으면 2차로 넘긴다(값과 뽑은 내용이 서로 맞지 않는 경우).
- `remaining_days()`는 처음에 김규림이 직접 쓰도록 비워 두었다가, 요청에 따라 Claude가 채웠다.
- 시험: 새 시험 3개(남은 날 형식, 새 2차 검사, 규칙 문장)와 기존 계약 시험의 남은 날 기대값을 고쳤다. 워커 시험 68개 통과.
- 첫 수정본으로 회귀를 돌리자 "이번 주는 힘들 것 같아요. 다음 주에 다시 연락 주세요"가 no에서 unknown으로 바뀌었다. 재통화 문장이 안 된다는 답까지 덮은 것이라, 정의 (4)의 뜻대로 '답 없이 재통화만 요청한 경우'로 좁혔다.
- 최종 회귀(3회 다수결, v4 라벨 초안): 주 정확도 140/149 → 143/149, 느슨한 정확도 142/149 → 146/149, 비싼 오류 1 → 0. 확정 137행은 느슨한 기준 104/104. 사례당 $0.0034. 경로 안내와 미확인 사이를 오가는 경계 2건은 더 고치지 않았다.
- 주의: 이번 수정은 190항목 회귀에서 본 오류를 보고 정한 부분이 있어, 수정 뒤 190항목 점수도 블라인드 수치가 아니다. 발표용 수치는 새 실통화 세트로 낸다.
