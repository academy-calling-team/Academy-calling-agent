## 프롬프트

최신버전으로 다시 배포하고 자동갱신설정도 가능하면 해봐

## 결과를 어떻게 썼는지

공동 API·큐·음성 목업 워커를 대상으로 OIDC/SSM 배포 권한과 GitHub Actions를 구성했다. 기존 DB와 설정을 재사용하며 스키마 자동 변경·기존 동의 시각 소급 기록은 하지 않는다. 프론트 가입 체크박스의 실제 선택값과 중계 전달을 보완했다. 프론트는 로컬 실행 방식이며 이 자동 배포로 사이트를 게시하지 않는다. 검증 범위와 운영 확인은 infra/SHARED_API_DEPLOY.md 참조.
