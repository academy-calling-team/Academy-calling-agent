# 판정 프롬프트 v3 (11/6)

- 날짜: 2026-11-06
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 11/4 10주차 회의 결과(학원 원문과 요약 병기, 불확실한 답 처리, 애매한 사례마다 프롬프트를 늘리지 말 것)를 LLM 판정에 반영한다.

## 프롬프트

```
v3 프롬프트 시작하자
멘토님께서 애매한거 나올때 마다 프롬프트를 늘릴 수는 없으니 근본적인 해결 방법이 없을까 고민해 보라고 하셨는데 어떻게 생각해?
그 방향으로 v3 고쳐줘
커밋하고 v3 실행까지 해줘
```

## 결과를 어떻게 썼는지

- Claude가 처음에는 '아마' 같은 짐작을 미확인으로 두는 규칙 한 줄을 추가하려 했다. 멘토 의견을 따라 이 방식은 버렸다.
- 대신 답의 내용(status)과 확실성(certainty: definite·guess·deferred)을 따로 받는 구조로 바꿨다. 확정하지 않은 답은 코드(`settle`)가 미확인으로 돌리고, 학원이 기운 쪽은 `leaning`에 남긴다.
- 학원 원문(`source_text`)은 LLM이 아니라 코드가 근거 발화 번호로 전사에서 꺼낸다. 요약의 숫자·요일이 원문에 없으면 요약 대신 인용 원문을 쓴다(`facts_ok`). Claude가 예문 19개로 시험했다.
- 강유준의 사람 작성 사례를 보기 전에 이 프롬프트를 커밋했다. 그 사례가 v3의 처음 보는 시험 세트다.
- 한계: 기존 190항목은 v2를 만들 때 이미 본 세트라, v3 개선 여부는 사람 작성 사례로 판단한다.
