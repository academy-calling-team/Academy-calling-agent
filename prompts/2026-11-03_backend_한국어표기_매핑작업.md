그러면 나는 프론트담당한테 question_label 에 연결해서 쓰시면 됩니다. 라고 전달하면되지?

### 추가 지시

아 그리고 두번째 답변에서의 answered도 사용자의 프론트화면에선 한글로 표기되는걸 목표로하니까 해당 상태에도 상태에따른 한글표기도 추가하는게좋을듯

위에서도 그렇고 아래에도 그렇고 한글표기란걸 나타내게 이름 직관적이게끔 kr 이라는 문구 붙여서 하는게좋을듯

## 결과를 어떻게 썼는지

기존 QUESTION_LABELS와 통화 상태/결과 매핑으로 상세조회 응답에 question_label_kr·status_label_kr·outcome_label_kr를 추가했다. question_code·status·outcome·ID와 DB 저장/워커 요청은 유지했다. answered는 통화 결과에서 연결됨, 통화 진행 상태에서는 통화 중으로 구분했다. 원문 요청의 question_label은 후속 지시에 따라 question_label_kr로 확정했다. API 명세·프론트 연결 예제와 HTTP 통합 시험을 함께 갱신한다. 프론트 화면 코드는 이번 작업 범위에 포함하지 않는다.
