## 기존 추가 작업과 이번 보완

- 기존 PR61 · 유종민의 질문별 추가 필드 저장/SQL, 학부모 근거 발화 조회, 학원 소유자/admin 전사 권한, consult 교정 구현과 작성자 커밋 보존
- 이번 보완 · 늦은 결과의 전사 조회를 최종 적용 여부와 분리, applied 값 제공·기존 권한/학부모 최종 결과 보호

## 검증·범위

API/격리 DB/권한·기존 결과 호환 회귀와 최신 PR 자동검사를 확인한다. 원격 main 병합·DB 적용·배포·실제 발신·외부 LLM 호출은 이번에 수행하지 않는다. 팀원 원문 프롬프트는 제공되지 않았으며 위 기존 작업 설명은 PR과 코드의 요약이다.
