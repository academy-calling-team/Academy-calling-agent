# 통화 끝 요약을 항목별 결과 한 문장으로 줄이기 (11/25)

- 날짜: 2026-11-25
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 11/25 실통화 전체 연결 시험 두 건에서 마지막 요약이 23.5초(86초 통화의 27%), 26초(134초 통화의 19%)였다. 학원 답을 "~라고 하셨습니다"처럼 다시 풀어 말해서 길다. 확인 기능은 남기고 길이만 줄인다.

## 프롬프트

```
푸시하고 PR 열어줘, 요약 후보도 PR만.
```

## 결과를 어떻게 썼는지

- Claude가 두 통화 전사를 ClawOps에서 받아 요약 길이를 쟀고, 서비스 에이전트 프롬프트(`voice/prompts/service_agent_prompt.txt`) 6번 후보를 만들었다.
  - 모든 질문의 답을 한 문장으로, 항목마다 결과만 말한다(예: "등원 차량 가능, 맞는 반 있음, 두 자리, 화요일·목요일 저녁 7시, 상담은 원장님 계실 때 다시 연락으로 정리했습니다.")
  - 학원 말을 다시 풀어 말하거나 '~라고 하셨습니다'를 붙이지 않는다
  - 끝인사를 "맞으시면 이대로 전해 드리겠습니다. 감사합니다."로 줄인다
- 요약을 아예 빼지 않은 이유: 11/24 변경(PR #75)으로 "네, 태워드려요" 같은 짧은 답은 따로 되짚지 않는다. 그래서 마지막 요약이 그런 답을 확인하는 유일한 자리다.
- 통화 2 요약(약 190자, 26초)에 대 보면 약 95자로 줄어 13초 안팎이 될 것으로 추정한다(통화당 10% 남짓). 실제 효과는 시험 통화로 잰다.
- 종료 원인 판정(`real_call.CLOSING`)은 새 끝인사의 "전해 드리"와 "감사합니다"로 그대로 마무리 인사를 알아본다.
- 운영 중인 서비스 에이전트는 바꾸지 않았다. PR 병합 뒤 `setup_service_agent.py update`로 반영한다(운영 변경이라 실행 전 확인).
- 워커·목업·에이전트 도구 시험 143개 통과(프롬프트 본문은 시험이 파일과 같은지만 확인).
