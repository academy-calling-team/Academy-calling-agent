# 질문별 판정 LLM 전환 평가

- 날짜: 2026-10-29
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 10/28 9주차 회의에서 멘토님이 키워드 사전 판정에 반대해("금토일 안될 것 같습니다" 같은 완곡한 부정 처리 어려움), LLM API 판정으로 바꾸기 전에 같은 시험 세트로 두 방식을 비교한다.

## 프롬프트

```
답변해석 딕셔너리 방식은 멘토님께서 반대하심 다른 방안 탐색(LLM등)
노션에서 10월 28일 회의(9주차회의) 참고
응 1번부터 진행해줘
```

## 결과를 어떻게 썼는지

- Claude가 대안 네 가지(통화 후 LLM 추출, 플랫폼 통화 후 분석, 통화 중 함수 호출 기록, LLM + 근거 검증)를 비교했고, 김규림이 'LLM 추출 + 근거 인용 검증'으로 오프라인 비교부터 하기로 정했다.
- `voice/judge_eval/`을 새로 만들었다. 워커 코드는 바꾸지 않았다. 시험 세트는 10/13 실통화 16통(정답지 `voice/prompts/test_script_v3.md`), 10/19 실통화 2통, 합성 26개다. 합성 사례는 Claude가 키워드 방식이 어려워할 말투를 골라 썼고 정답은 김규림 판정 기준(10/19)으로 붙였다.
- 키워드 방식 기준선: 실통화 56개 중 54개 맞음, 합성 28개 중 20개 맞음(예↔아니오 뒤바뀜 6건).
