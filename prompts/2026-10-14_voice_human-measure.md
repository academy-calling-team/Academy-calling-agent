# 뷰어로 직접 잰 응답 지연 정리

- 날짜: 2026-10-14
- 작성자: 김규림
- 사용한 도구: Claude (Claude Code)
- 목적: 뷰어로 10/13 녹음 16개의 화자를 직접 정해 잰 결과(스크린샷)를 자동 분석과 비교해 정리

## 프롬프트

```
툴 이용해서 내가 직접 화자분리 후 측정한거 스크린샷으로 human_result에 정리해놨어 보고 다시 정리해줘
```

```
스크린샷과 함께 커밋해줘
```

## 결과를 어떻게 썼는지

- 직접 측정은 김규림이 뷰어(`experiments/latency/viewer/latency_viewer.html`)로 했다. 스크린샷 16장은 `experiments/latency/data/human_result/`에 그대로 두었다.
- Claude가 스크린샷의 응답 간격 값을 `human_1013.csv`에 옮겨 적고, 자동 분석 결과와 짝지어 비교했다. 차이가 큰 곳 7군데는 뷰어와 같은 방식으로 경계를 다시 계산해, 차이가 소리 크기 기준(뷰어 −60dB, 자동 −50dBFS)에서 나온다는 것을 확인했다. 결과는 `experiments/latency/README.md`의 '직접 측정과 비교 (10/14)'에 정리했다.
- 비교하다 찾은 뷰어 문제 두 가지를 Claude가 고쳤다. 응답 수가 짝수일 때 중앙값이 작은 쪽 값으로 나오던 것을 고쳤고, '말소리 기준' 선택(기본 −50dB)을 넣었다.
- 직접 들어 확인할 곳 두 군데(ClawOps D 59.98~60.18초, Vapi A2 첫 응답)는 README의 '확인할 것'에 남겼다.
