[회의내용]
* 회의에서 나온 아이디어 및 회의 내용을 기술한다.

1. 팀원 소개 및 담당 역할 확인
   1) 음성 파이프라인 - 김규림
   2) 백엔드 및 텔레포니 연동 - ○○○
   3) 프론트엔드 - ○○○
   4) 팀원별 기존 개발 경험(실시간 1:1 통신 구현, 도서관 좌석예약 시스템, 공공데이터 활용 프로젝트, 오픈소스 프로젝트) 공유

2. 프로젝트 수행 목표 및 기대사항 공유
   1) 멘토가 팀원 각자에게 본 프로젝트를 통해 얻고자 하는 바를 명확히 밝힐 것을 요청함
   2) 실시간 처리 구조에 대한 이해 / 목표가 명확한 과제를 기한 내 완수하는 실무형 경험 / 음성·음향 분석 분야 역량 확보 / 신입 개발자 공통 역량 습득
   3) 멘토는 팀의 목표에 맞추어 적극적으로 개입하는 방식으로 멘토링을 진행하기로 함

3. 과제 내용 파악 - 서비스 방향 확정
   1) 제안서상의 발신 대행 서비스가 학원이 아니라 학부모를 대행하는 구조임을 확인함
   2) 맞벌이 학부모는 학원이 전화를 받을 수 있는 오전·이른 오후에 통화가 어렵고, 학원은 학부모가 통화 가능한 저녁 시간에 수업 중이어서 상담 전화가 지속적으로 지연되는 문제가 존재함
   3) AI 보이스 에이전트가 학부모를 대행하여 학원에 발신하고, 통학 가능 여부·수강 적합성 등 문의 사항을 확인한 뒤 결과를 정리해 학부모에게 전달하는 구조로 확정함
   4) 1차 목표인 콜 오케스트레이터의 처리 흐름 : 학부모 요청 접수 → 발신 가능 시간대 검증 → 학원 운영시간 내 에이전트 발신 → 통화 음성 인식 및 텍스트화 → 결과 정리 후 학부모 전달
   5) 제안서의 '우선순위 부여'는 큐에 적재된 발신 요청을 시간대별로 정렬·선정하는 기능임을 확인함

4. 개발 방침 - 상용 툴 활용으로 전환
   1) 제안서에 기술된 수준은 상용 서비스를 사용하지 않고 저수준부터 구현하는 경우를 전제한 것으로, 한 학기 내 완수가 어렵다는 멘토 의견이 있었음
   2) 상용 보이스 에이전트 서비스를 적극적으로 활용하고, 정보 확인·저장·통신을 담당하는 자체 서버는 반드시 별도로 구축하기로 함
   3) 초기 과제로 상용 보이스 에이전트 툴 리서치를 수행하며, 기능 특성·가격·자체 서버 연동 가능 여부를 기준으로 비교 후 선정하기로 함

5. 설계 중심 진행 방침
   1) 개발 방법론은 워터폴 방식을 채택함. 전체 흐름을 먼저 이해하고 설계를 확정한 뒤 구현에 착수함
   2) 자체 서버, 보이스 에이전트 서버, 070 가상번호 발급 서버 간 데이터 흐름을 시퀀스 다이어그램 등 설계 문서로 문서화하기로 함
   3) 작성된 설계 문서는 추후 요구사항 변경 시 판단 기준으로 활용함
   4) 구현보다 설계 역량이 개발자의 차별점이며, 수정 비용이 구현 비용보다 크므로 통제 가능한 범위로 태스크를 분할해 구현할 것을 멘토가 강조함

6. 테스트 설계 선행
   1) 구현 후에 테스트를 작성하면 테스트가 구현에 맞추어지므로, 테스트 방식을 먼저 확정한 뒤 개발에 착수하기로 함
   2) AI 에이전트는 동일 입력에도 응답이 달라지는 비결정적 특성이 있어 검증 기준 수립이 어려우므로, 케이스별 판정 가이드라인 구축을 선행 과제로 설정함

7. 산출물(논문) 작성 전략
   1) 설계 문서 작성 단계까지 완료하면 논문 작성 기반이 확보됨을 확인함
   2) 구현이 조기에 완료될 경우 구현 결과 기반 논문으로, 구현에 시간이 소요될 경우 설계 문서 기반 이론 논문으로 작성하는 두 경로를 확인함
   3) 산출물을 후반에 착수하면 프로젝트 진행이 중단되므로 초반부터 병행하기로 함

8. 선행 학습 항목 확인
   1) 웹소켓 및 비동기 통신 - HTTP와 달리 연결이 유지되며 양방향 입출력이 동시에 발생하고 입력이 중첩될 수 있는 구조에 대한 이해가 필요함
   2) 도커, 서버 호스팅 및 배포 - 구현 범위와 무관하게 배포 단계까지 경험하는 것을 목표로 함

9. 운영 사항 협의
   1) 정기 회의는 매주 수요일 18시 이후로 하며, 멘토는 온라인으로 참여하기로 함
   2) 9월 16일(수)은 프로젝트 수행 계획 발표가 예정되어 별도 회의를 진행하지 않음
   3) 차차주 회의는 추석 연휴 전날에 해당하여 팀원 가능 시간을 취합한 후 일정을 조정하기로 함
   4) 유료 API 및 클라우드 비용 결제 방식은 지도교수님께 확인 후 멘토에게 회신하며, 필요 시 기업에서 계정을 제공하기로 함
