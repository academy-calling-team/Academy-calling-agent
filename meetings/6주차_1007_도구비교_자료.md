# 음성 파트 도구 비교 — 6주차 회의(10/7) 자료

작성 2026-10-06 · 음성 파이프라인 김규림
요청 근거: 5주차 회의(9/29) 멘토 요청 — 국내 사용 조건·서버 위치·비용·실제 통화 지연 비교, 유료 시험 필요 도구와 지원 요청 정리

---

## 요약

- **Vapi**는 구현이 쉽지만 서버가 미국·EU뿐이고, 한국 발신번호를 자체로 주지 않습니다.
- **ClawOps**는 국내 070 발급과 함께 **통화 중 실시간 양방향 오디오(WebSocket)**를 제공합니다. 국내 회선 위에 우리 파이프라인을 직접 올릴 수 있는 경로입니다.
- 제안: **두 경로를 유료로 시험해 같은 시나리오로 실통화 지연을 비교한 뒤 확정**합니다. 예상 비용은 합계 약 10만 원(예산의 20%)입니다.

---

## 정정 (9/29 회의 발언)

> "OpenAI Realtime은 국내 070에 직결할 수 없다"

→ **정정합니다.** 우리가 회선을 직접 붙이면 코덱(G.711↔Opus)·TLS 조건이 걸리는 건 맞지만, ClawOps가 **SIP 트렁크 부가서비스로 070 → OpenAI Realtime·ElevenLabs Agents 연결을 공식 문서로 지원**합니다. 다만 문서는 **수신(인바운드) 기준**이고, 발신에도 쓸 수 있는지는 확인이 필요합니다.

## 비교표

| 항목 | A안 Vapi | B안 ClawOps + 자체 파이프라인 | (참고) ClawOps SIP → OpenAI Realtime / ElevenLabs |
|---|---|---|---|
| 서버 위치 | 미국(api.vapi.ai), EU 옵션. **아시아 리전 없음.** 턴 판정·끼어들기 처리는 Vapi 인프라에서만 동작 | 회선·미디어는 국내 처리(서비스 소개 기준). STT·LLM·TTS 위치는 우리가 선택 | 회선은 국내, AI는 OpenAI·ElevenLabs 서버 |
| 한국 발신번호 | 자체 무료 번호는 미국 번호이고 **발신 불가**. Twilio 등 번호를 가져오거나 BYO SIP 트렁크 필요 | **070 직접 발급, 발신 지원** | 070 |
| 070 연결 방식 | BYO SIP 트렁크(digest 인증). 070 사업자가 외부 플랫폼용 **발신 SIP 트렁크**를 줘야 함 | REST로 발신 → 통화 오디오가 우리 서버 WebSocket으로 들어옴 | SIP 트렁크 부가서비스, TLS |
| 실시간 오디오 | 플랫폼 내장 | 양방향 WebSocket, **G.711 μ-law 8kHz, 20ms 프레임** | 플랫폼 내장 |
| 끼어들기 | 플랫폼 내장 | `clear` 이벤트로 출력 버퍼 즉시 비움. 발화 감지는 우리가 구현 | 플랫폼 내장 |
| ARS(DTMF) | 지원 (IVR 내비게이션 문서, 네이티브 DTMF) | 양방향 `dtmf` 메시지 | 확인 필요 |
| 턴 판정 | Vapi 설정값으로 조정 | **우리가 구현** | 플랫폼 내장 |
| 요금 | 플랫폼 $0.05/분 + STT·LLM·TTS 별도 → 합계 약 $0.10~0.30/분. Twilio 경유 시 한국 휴대폰 발신 $0.0524/분 + 번호 월 $1.15 | Trial 3일 무료(발신 10분) / 개인 ₩19,000/월(동시 1, 발신 100분) / 비즈니스 ₩99,000/월(동시 10, 발신 1,000분) + 부가 ₩10~200/분 + AI API 비용 | SIP 부가서비스 요금 확인 필요 + AI 사용료 |
| 개인정보 | 통화 음성·전사가 해외에서 처리 → **국외 이전 고지·동의 검토 필요**. 녹음 저장소는 지역 지정 가능 | 회선·녹음은 국내. AI API가 해외면 그 부분만 국외 이전 | AI 처리가 해외 |
| 예상 지연 구조 | 오디오가 한국↔미국 왕복 → **약 +150~250ms 추정** (실측 필요) | 회선 구간은 국내. AI API 위치가 지연을 좌우 | 회선 국내 + AI 해외 |
| 구현 부담 | 낮음 | 높음 (턴 판정·끼어들기 직접 구현) | 낮음 |
| 체험 | $5 무료 크레딧, **브라우저 통화 확인 완료(9/28)** | 카드 없이 3일 | 부가서비스 신청 필요 |

**판단**: A안은 빨리 돌아가고, B안은 국내 조건(번호·서버·개인정보)에 맞습니다. B안의 구현 부담(턴 판정·끼어들기)은 음성 파트가 원래 맡기로 한 영역이라, 학기 목표와도 맞습니다.

## 실통화 지연 — 아직 실측 전

멘토 말씀대로 브라우저 시험만으로 확정하지 않습니다. 유료 시험 승인 후 아래처럼 측정합니다.

- **같은 시나리오로 A·B 각각 본인 휴대폰에 10통**
  - 시나리오: 정상 응답(질문 2개), 끼어들기
- **측정**: 통화 녹음 파형에서 상대 발화 종료 → AI 첫 소리까지. 평균과 p95
- **리전 비용 따로 측정**: 서울에서 `api.vapi.ai` 연결 왕복 시간
- **분담 제안**: A안 Vapi 실통화 — 강유준 / B안 ClawOps 파이프라인 — 김규림

## ClawOps에 문의할 것

1. 070 **발신**을 외부 SIP(예: Vapi BYO SIP 트렁크)로 받을 수 있는지 — 발신용 SIP 트렁크 호스트·digest 인증정보 제공 여부
2. SIP 트렁크 연결 부가서비스 요금, OpenAI Realtime 연결이 **발신**에도 되는지
3. 서버 리전과 WebSocket 스트림 지연 수치
4. 학생 팀 명의로 개인 플랜 가입 가능 여부
