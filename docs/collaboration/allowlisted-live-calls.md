# 허용 번호로 학원 실발신

개발 서버에서 등록된 학원의 번호가 승인 목록에 있으면 로그인한 학부모 계정으로 실제 전화 문의를 접수할 수 있다. 허용 목록 밖 번호도 학원 정보로 저장할 수 있고, 문의 화면에 발신 불가가 표시된다. 저장한 전화번호는 공개 학원 목록에 노출하지 않는다.

- `010XXXXXXXX`와 `010-XXXX-XXXX`는 실제 발신 조건에서 같은 번호로 비교한다. 워커로는 `+8210XXXXXXXX` 형식을 전달한다.
- 한국 시간 기준 매일 24시간 응대는 학원 등록·관리 화면의 체크 항목으로 저장한다. API에서는 `always_open: true`와 `call_hours: []`를 함께 보낸다. 기존 요일·시간대 설정도 계속 지원한다.
- 실제 문의는 학부모 계정과 등록 학원 번호를 확인한다. 큐 예약·발신 전달 시 서버의 저장 상태와 허용 번호를 다시 확인하고 워커도 별도로 검증한다. 문의당 최초 발신 1회의 기존 제한을 유지한다.

## 배포 후 운영 절차

1. 새 코드로 배포된 API·큐·워커를 확인한다. 기존 고정 시험 모드에서 승인 번호 방식으로 바꾸려면 실제 발신을 끈 상태에서 시작한다.
2. EC2의 대화형 운영자 터미널에서 `sudo python3 /opt/team8-shared-api/deploy/real-call-test.py configure-allowlist`를 실행한다. 동의한 팀원 수신 번호를 쉼표로 구분해 입력한다. 번호는 입력 중에 보이며, 저장 직전에 국내 표기로 다시 표시된다. 맞으면 `CONFIRM`을 입력한다. 틀렸으면 Enter로 취소하고 다시 실행한다. ClawOps 값이 필요한 경우 숨김 입력으로 받는다. 공유 화면이나 세션 내용이 녹화되는 터미널에서는 다른 사람에게 번호가 보일 수 있으므로 개인 운영 터미널을 사용한다. 번호는 명령 인수나 Git에 넣지 않는다.
3. 학원 계정으로 새 학원을 가입·등록하고 전화번호와 24시간 응대를 저장한다. 이번 초기 학원명은 `실험학원(김규림)`이다. 그 학원이 저장한 번호를 운영자와 수신자가 맞춰 본다.
4. `status`로 모드, 허용 번호 개수, API·워커 목록 일치 여부를 확인한다. 수신자가 동의한 경우 운영자가 `enable`을 실행한다. 개발 서버가 계속 허용할 대상은 이 목록에 남아 있는 번호로 제한된다.
5. 서로 다른 일반 학부모 계정의 접수 가능 여부와 목록 외 번호의 발신 차단을 확인한다. 실제 리허설은 수신 준비 시점에 한 건으로 진행한다. `disable`을 실행하면 번호와 학원 정보를 유지한 채 실제 발신을 멈춘다.

별도 DB 마이그레이션은 없다. 기존 개발 자료를 정리하는 작업은 대상과 백업을 검증한 뒤 별도로 실행한다.
