# ERD 필드·관계 설명

코드 기준 21테이블 / 20외래키. 필수는 DB NULL 불가를 뜻하며 화면 입력 필수와는 다를 수 있다.
복합 고유키에 포함된 필드는 단독 UK로 표시하지 않는다. 관계선의 자식 0은 아직 관련 행이 없는 상태를 허용한다.

## DB가 자동 보장하지 않는 연결

- mock_worker_receipts.call_id는 실제 코드의 PK이며 FK가 아니다. 도형을 잇는 선을 추가하지 않았다.
- review_actions.actor와 reviewer 계열은 문자열 기록이며 accounts로 향하는 FK가 아니다.
- answers의 call_id와 question_id는 각각 FK지만 같은 문의에 속하는 조합인지까지 DB 복합 FK로 제한하지 않는다. 애플리케이션 검증 대상이다.
- review_holds의 inquiry_id와 call_id 역시 각각 FK이며 동일 문의 정합성은 애플리케이션에서 확인한다.
- 통화 결과 원본 results와 교정 이력 result_corrections를 구분한다. 교정은 원본 덮어쓰기와 다르다.
- w5_inquirers.token_hash는 이전 구조 보존 필드이며 6주차 공개 인증은 accounts/sessions 기준이다.
