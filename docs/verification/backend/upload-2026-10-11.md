## 남은 연결 작업

- 목업 학원 phone=None을 음성 워커가 거절하는 문제에 대한 합의.
- 기본 run_queue는 BE 자체 MockWorker를 사용한다. 음성팀 HTTP 워커 선택 및 자체 가짜 결과 생성과의 분리.
- BE INTERNAL_API_KEY와 음성 INTERNAL_KEY의 설정 매핑, URL·PC 간 접근 경로.
- WorkerHttpAdapter가 409 후 조회로 성공을 반환하는 예외 처리 개선.
- 결과 재전송·늦은 결과·거절/ARS/고지/시간 미정 재통화 시나리오.
- 수강료/교재비는 현재 양쪽 실행 코드에 없음. 대본의 시험 항목을 확정 요구사항으로 취급하지 않음.

프론트·음성 실제 서버 왕복, 최신 AWS API 배포, Docker·새 PC 재현, 실제 전화·문자 발신은 미검증/미구현 범위를 유지한다.
