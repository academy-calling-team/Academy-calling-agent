## 100건의 의미와 한계

10개 합성 그룹(정상 답변/부분 답변/부정 답변/부재중 재시도/통화중 재시도/기계 응답 재시도/잘못된 번호·후속 검토/거절/시간 미정 재통화·검토 종료/고지 누락)으로 입력·워커 결과를 만들었다. 질문 개수 1~6을 반복한다.

FastAPI 계약은 프로세스 내부 TestClient, Redis/MySQL은 실제 로컬 서비스를 사용했다. Vapi 형식은 합성 메시지이고 목업 답변은 사전 생성 값이다. 월요일 14:00 KST 가상 시계를 10초 단위로 진행해 재시도·운영시간을 재현했다. 실제 지연/한국어 품질/외부 API/전화망을 측정하지 않았다.

별도 HTTP 검증은 실제 loopback 포트 18771/18772를 사용했다. readiness200, 타인 조회404, member ops403, 로그아웃 후401, 정상 결과의 부정/미확인/class_time 세 답변을 확인했다. 포트 프로세스는 검증 뒤 종료했다.

가상 데이터는 기존 로컬 개발 DB에 누적된다. 따라서 ops/overview 전체 집계는 이 100건만의 통계가 아니다. 결과 JSON의 완료 70건은 실서비스 성공률이 아니라 사전 시나리오를 만족한 상태 수이다.
